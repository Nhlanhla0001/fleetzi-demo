How setup works

A simple path from machine review to a verified fleet record.

  1. 1
    Review the machineConfirm the exact equipment, where it works and what information matters operationally.
  2. 2
    Confirm available informationIdentify which location, operating, diagnostic or sensor readings can be supported reliably.
  3. 3
    Install and configureComplete the field setup for the machine and its working conditions.
  4. 4
    Verify connectivityConfirm the machine is reporting consistently and is assigned to the correct record.
  5. 5
    Verify readingsCheck the available fields against the real machine before they are trusted operationally.
  6. 6
    HandoverMake the verified machine available in Fleet, Live Map and other applicable modules.

What may be available

The exact data depends on the machine and the agreed setup.

Location & movement
Current or last-known position, movement and site/geofence context.
Machine hours
Verified operating-hour or meter information where available.
Fuel
Fuel information where the machine or approved installation supports it.
Diagnostics
Compatible fault or machine-condition information where available.
Additional sensors
Extra readings where the operating requirement justifies them.
Verified data onlyNot every machine exposes the same information. Unavailable readings remain unavailable rather than being estimated.
